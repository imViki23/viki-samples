
# Differentiation Formulas Reference Sheet

---

## 1. General Differentiation Rules

| Operation / Rule | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ or $f'(x)$) |
| :--- | :--- | :--- |
| **Constant Rule** | $c$ | $0$ |
| **Power Rule** | $x^n$ | $n x^{n-1}$ |
| **Constant Multiple Rule** | $c \cdot f(x)$ | $c \cdot f'(x)$ |
| **Sum / Difference Rule** | $f(x) \pm g(x)$ | $f'(x) \pm g'(x)$ |
| **Product Rule** | $f(x) \cdot g(x)$ | $f'(x)g(x) + f(x)g'(x)$ |
| **Quotient Rule** | $\frac{f(x)}{g(x)}$ | $\frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$ |
| **Chain Rule** | $f(g(x))$ | $f'(g(x)) \cdot g'(x)$ |

---

## 2. Exponential & Logarithmic Functions

| Function Type | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ ) |
| :--- | :--- | :--- |
| **Natural Exponential** | $e^x$ | $e^x$ |
| **General Exponential** | $a^x$ ($a > 0$) | $a^x \ln(a)$ |
| **Natural Logarithm** | $\ln(x)$ ($x > 0$) | $\frac{1}{x}$ |
| **General Logarithm** | $\log_a(x)$ ($a > 0, a \neq 1$) | $\frac{1}{x \ln(a)}$ |

---

## 3. Trigonometric Functions

| Trig Function | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ ) |
| :--- | :--- | :--- |
| **Sine** | $\sin(x)$ | $\cos(x)$ |
| **Cosine** | $\cos(x)$ | $-\sin(x)$ |
| **Tangent** | $\tan(x)$ | $\sec^2(x)$ |
| **Cosecant** | $\csc(x)$ | $-\csc(x)\cot(x)$ |
| **Secant** | $\sec(x)$ | $\sec(x)\tan(x)$ |
| **Cotangent** | $\cot(x)$ | $-\csc^2(x)$ |

---

## 4. Inverse Trigonometric Functions

| Inverse Trig Function | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ ) |
| :--- | :--- | :--- |
| **Inverse Sine** | $\arcsin(x)$ or $\sin^{-1}(x)$ | $\frac{1}{\sqrt{1 - x^2}}$ |
| **Inverse Cosine** | $\arccos(x)$ or $\cos^{-1}(x)$ | $-\frac{1}{\sqrt{1 - x^2}}$ |
| **Inverse Tangent** | $\arctan(x)$ or $\tan^{-1}(x)$ | $\frac{1}{1 + x^2}$ |
| **Inverse Cosecant** | $\operatorname{arccsc}(x)$ or $\csc^{-1}(x)$ | $-\frac{1}{|x|\sqrt{x^2 - 1}}$ |
| **Inverse Secant** | $\operatorname{arcsec}(x)$ or $\sec^{-1}(x)$ | $\frac{1}{|x|\sqrt{x^2 - 1}}$ |
| **Inverse Cotangent** | $\operatorname{arccot}(x)$ or $\cot^{-1}(x)$ | $-\frac{1}{1 + x^2}$ |

---

## 5. Hyperbolic Functions

| Hyperbolic Function | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ ) |
| :--- | :--- | :--- |
| **Hyperbolic Sine** | $\sinh(x)$ | $\cosh(x)$ |
| **Hyperbolic Cosine** | $\cosh(x)$ | $\sinh(x)$ |
| **Hyperbolic Tangent** | $\tanh(x)$ | $\operatorname{sech}^2(x)$ |
| **Hyperbolic Cosecant** | $\operatorname{csch}(x)$ | $-\operatorname{csch}(x)\coth(x)$ |
| **Hyperbolic Secant** | $\operatorname{sech}(x)$ | $-\operatorname{sech}(x)\tanh(x)$ |
| **Hyperbolic Cotangent** | $\coth(x)$ | $-\operatorname{csch}^2(x)$ |

---

## 6. Inverse Hyperbolic Functions

| Inverse Hyperbolic Function | Function ($f(x)$) | Derivative ($\frac{d}{dx}[f(x)]$ ) |
| :--- | :--- | :--- |
| **Inverse Hyperbolic Sine** | $\operatorname{arcsinh}(x)$ | $\frac{1}{\sqrt{x^2 + 1}}$ |
| **Inverse Hyperbolic Cosine** | $\operatorname{arccosh}(x)$ ($x > 1$) | $\frac{1}{\sqrt{x^2 - 1}}$ |
| **Inverse Hyperbolic Tangent** | $\operatorname{arctanh}(x)$ ($|x| < 1$) | $\frac{1}{1 - x^2}$ |
